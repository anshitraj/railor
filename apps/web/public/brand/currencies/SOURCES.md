# UAE dirham symbol

`aed.svg` is downloaded unchanged from the MIT-licensed dirham project:
https://github.com/pooyagolchian/dirham/blob/main/packages/dirham-symbol/src/svg/dirham.svg.
That project identifies the CBUAE as the glyph's source. The CBUAE's official
SVG zip was unavailable to this download client. Reference:
https://www.centralbank.ae/media/jlhi41xu/dirham_currency_symbol_guideline_english.pdf.

Used as a currency field in a route diagram, not as Railor branding. Original
proportions are retained, and a text label is always present.
